# CLAUDE.md — правила работы с этим репозиторием

Читается автоматически в начале каждой сессии. Здесь только то, что нужно,
чтобы не сломать проект. Продуктовые решения и бэклог — в `PRODUCT_ROADMAP.md`.

## Что это за проект

«АвтоПост» — сервис, который пишет посты для Telegram-каналов и публикует их:
автоматически или после подтверждения владельца. Прод: https://projectautopost.ru
(Timeweb Cloud). Модель — DeepSeek v4 flash через Yandex AI Studio.

## Структура

| Что | Где |
|---|---|
| API, роутинг, отдача страниц | `main.py` (~1900 строк) |
| Модели БД | `database.py` |
| Генерация постов, промпты | `generator.py` |
| Планировщик, очередь, публикация, подписки | `tasks.py` |
| Оплата (ЮKassa) | `billing.py` |

| Лендинг | `static/landing.html` + `landing.css` |
| Юридические документы | `static/legal/` |

## Обязательные правила

### 1. Фронтенд: никогда не редактировать `static/app.js`

Это собранный файл. Правки — только в `app.partNN.js`, после чего пересобрать:

```bash
cd static && cat app.part*.js > app.js && node --check app.js
```

И **поднять версию кэша** в `static/index.html` (`?v=ГГГГММДДб` → следующая
буква) — иначе браузеры продолжат грузить старые скрипты.

### 2. БД: никаких `ALTER TABLE` на задеплоенных таблицах

Новая логика — через **новые таблицы** (`PostApproval`, `TelegramIdentity`,
`Subscription`, `IdempotencyKey`, `LandingEvent`, `ProductEvent`,
`TrafficAttribution` сделаны именно так). `create_all()` создаёт их безопасно.

Если дрейф схемы уже случился — добавить колонку **идемпотентной миграцией**
в `_add_missing_columns()` (`database.py`) с проверкой через `inspector`
**перед** изменением. Примеры там уже есть.

Аналитические таблицы (`LandingEvent`, `ProductEvent`, `TrafficAttribution`)
намеренно **без FK** на `user.id` — чтобы не ломать удаление аккаунта.
Не добавлять FK в них.

### 3. Удаление аккаунта — минное поле

`delete_account()` в `main.py` уже трижды падал в проде на FK-нарушениях
(`User.referred_by`, `IdempotencyKey`, `PostApproval` + `TelegramIdentity`),
а четвёртый (`Subscription`) поймали тестом до прода.
**Добавили новую таблицу с FK на `user.id`, `post.id` или `channel.id` —
допишите её очистку в `delete_account()`.**

Ловушка внутри ловушки: при неизвестном FK шаг 7 не отдаёт ошибку, а
анонимизирует запись и возвращает `{"ok": true}`. Проверять надо не код
ответа, а что строки в базе исчезли — иначе провал выглядит как успех.

Тесты в `test_account_deletion.py`. Обычный прогон уже проверяет FK
(`conftest.py` включает `PRAGMA foreign_keys=ON`), но перед выкладкой лучше
прогнать на настоящем Postgres:

```bash
PYTEST_DATABASE_URL="postgresql://postgres:postgres@localhost:5432/autopost_test" \
  python3 -m pytest test_account_deletion.py -q
```

### 4. Ничего не публикуется в канал молча

Пост уходит к подписчикам только если: включён автопилот, пользователь нажал
«Опубликовать», или истёк **явно показанный** таймер подтверждения. Любая
правка, которая это ослабляет, — ошибка.

### 5. Интерфейс не обещает того, чего система не делает

Проверено на своих же граблях: «опубликуется сам через 30 мин» показывалось
постам без таймера; «соберём очередь на неделю» не собирало ничего;
«посты появятся автоматически» — на канале, для которого генерация не
запускается вовсе. Прежде чем написать обещание в UI, найдите код, который
его выполняет.

### 6. Работает из России без VPN

У отрисовки не должно быть **ни одной** внешней зависимости. Шрифты лежат
локально (`static/fonts/`), потому что `@import` на Google Fonts держал
страницу белой 25 секунд. Внешние скрипты — только асинхронно и с таймаутом.
Перед добавлением любого CDN: он доступен из РФ без VPN?

### 7. Деньги — с максимальной осторожностью

Автосписания защищены тремя слоями (детерминированный `Idempotence-Key` по
периоду, `last_period_key`, метка платежа = ключ периода). При неизвестном
исходе запроса платёж **не** помечается `failed` — деньги могли уйти.
Цена подписки зафиксирована в `Subscription.price_rub`: повышение тарифов
не должно менять списания уже подписанным.

### 8. Комментарии объясняют «почему», а не «что»

Код виден и так. В комментарии — причина решения, желательно с фактом:
что сломалось, как проявлялось, почему сделано именно так. Такие комментарии
в этом репозитории уже спасали от повторения багов.

### 9. Язык — русский

Интерфейс, комментарии, коммиты, документация. Без канцелярита: у фраз
должны быть подлежащие («мы опубликуем пост», а не «будет опубликовано»).

## Проверки перед коммитом

```bash
python3 -m pytest -q          # ожидается 68 passed, 6 skipped
python3 -m py_compile main.py tasks.py database.py generator.py billing.py
cd static && cat app.part*.js > app.js && node --check app.js
rm -rf __pycache__
```

Тесты поднимают приложение в этом же процессе (`conftest.py`), поэтому сервер
запускать не нужно и БД используется временная — боевой `DATABASE_URL` из
окружения намеренно игнорируется.

Локальный запуск:

```bash
DATABASE_URL="sqlite:///./local.db" TICK_SECONDS=99999 \
  python3 -m uvicorn main:app --port 8000
```

`TICK_SECONDS=99999` отключает фоновую генерацию — иначе локальный сервер
начнёт тратить реальные токены.

Postgres для проверки миграций и FK:

```bash
service postgresql start
sudo -u postgres psql -c "CREATE DATABASE autopost_test;"
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/autopost_test" ...
```

Браузер (Playwright): Chromium уже установлен, `playwright install` не нужен.

```python
pw.chromium.launch(executable_path="/opt/pw-browsers/chromium-1194/chrome-linux/chrome",
                   args=["--no-sandbox"])
```

## Известные проблемы (честно)

- **Тесты покрывают не всё, что дорого.** `python3 -m pytest -q` даёт
  63 прошедших и 6 пропущенных (27.07). Пропущен `test_quickstart_flow.py`:
  он тратит настоящие токены модели, запуск по `RUN_LLM_TESTS=1`. Не покрыто
  вообще: удаление аккаунта, дедупликация постов, биллинг — то есть ровно то,
  что уже ломалось в проде. Зелёный прогон это не ловит.
- **Деплой ломается**: Timeweb периодически не может склонировать репозиторий
  с GitHub (таймаут к `github.com:443`). Это сеть на стороне хостинга, не
  авторизация. Обходной путь — ручная загрузка изменённых файлов.
- **`Post.tokens_used` — внутренняя единица учёта, не токен провайдера.**
  По биллингу расхождение примерно шестикратное. Умножать эти числа на цену
  Yandex напрямую **нельзя** — см. `/api/internal/token-economics` со сверкой.
- **Reasoning-токены DeepSeek не проверены.** В `generator.py` два соседних
  комментария противоречат друг другу: работает ли `thinking: disabled`.
  Смотреть строку `[llm-usage]` в логах прода.
- **Автоплатежи ЮKassa не подключены** — на согласовании. Пока
  `SUBSCRIPTION_ENABLED=false`, оплата разовая.
